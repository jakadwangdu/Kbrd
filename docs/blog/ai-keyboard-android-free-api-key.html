How to use AI on your Android keyboard for free

An AI assistant on your keyboard can fix grammar, rewrite a message, translate it or draft a reply without leaving the app you are typing in. You do not need a subscription. You need a free API key from an AI provider, and a keyboard that lets you paste it in. Kbrd does exactly that.

What an API key is

An API key is a private password that lets an app talk to an AI model on your behalf. Providers such as Groq, OpenRouter and Google AI Studio offer free plans for personal use. Limits and available models change over time, so check each provider’s own page for the current details.

Set it up in Kbrd

  1. Install Kbrd and turn it on as your keyboard.
  2. Create a free key with a provider. Groq, OpenRouter and Google AI Studio each have a key page.
  3. Open the Kbrd app and tap Set up AI.
  4. Pick your provider, paste the key, then tap Load models and choose one.
  5. Tap Save, then Test. A short confirmation means you are ready.

Use it while you type

Tap the sparkle icon above the keys. Choose an action such as Fix grammar, Rewrite, Shorter, Friendly, Formal or Translate. Select some text first to change only that part, or select nothing and Kbrd uses the text before your cursor. Use Reply to copied to answer a message you just copied, and Ask AI to type a question and get the answer in place. You can always tap Undo.

Privacy

Kbrd contacts your provider only when you tap an AI action, and it sends only the text for that action. It never runs in password fields. Your key is encrypted on your phone with the Android Keystore, and Kbrd has no servers of its own. Read the full privacy policy.

Tips for free plans

  • If you see a rate limit message, wait a moment and try again.
  • Smaller models are faster and usually good enough for rewriting and translating.
  • Open-source models served by these providers work the same way as any other model.
