How to install an APK on Android safely

An APK is the file format Android apps are installed from. Apps in the Play Store are installed for you, but you can also install an APK directly. That is useful for small projects, but it means you are responsible for checking where the file came from.

Before you download

  • Download only from the developer’s official page. For Kbrd that is the GitHub releases page.
  • Check that the file name and the release match what the developer describes.
  • Avoid APK mirror sites and links shared in chats, because you cannot tell what has been changed.

Installing

  1. Open the downloaded file from your browser or Files app.
  2. When Android asks, allow installs from that one app only, for example your browser.
  3. Tap Install and wait for the confirmation.
  4. Go back to settings and switch the permission off again for the browser.

Check after installing

  • Open the app’s permissions and make sure each one makes sense. A keyboard might ask for the microphone for voice typing, and for internet only if it has online features.
  • If Play Protect offers to scan the app, let it.
  • Keep your previous version’s name in mind. Debug builds are signed with a different key each time, so Android may refuse to update over an older install. Uninstall the old version first, then install the new one.

If something looks wrong

Uninstall the app, clear the downloaded file, and ask the developer. Kbrd’s issues page is on GitHub.
